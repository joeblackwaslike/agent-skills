# Privacy Policy

Serena respects your privacy and is committed to protecting your personal information. 

When using Serena, no personal data or data about the project being worked on is sent to any external servers.
We collect only the following anonymous usage data whenever Serena is started:

 * the version of Serena being used,
 * the operating system being used,
 * the Serena agent interface being used,
 * the language backend being used,
 * the enabled status of the Serena Dashboard,
 * the enabled [Serena agent context](contexts)

This data is collected strictly to help us understand Serena usage.

If you want to opt out of usage data reporting, set the environment variable `SERENA_USAGE_REPORTING` to `false`.
