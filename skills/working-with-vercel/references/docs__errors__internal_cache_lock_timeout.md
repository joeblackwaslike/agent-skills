# INTERNAL_CACHE_LOCK_TIMEOUT

The `INTERNAL_CACHE_LOCK_TIMEOUT` error occurs when CDN is accessing internal cache.

**Error Code:** `500`

**Name:** Internal Server Error

## Troubleshoot

To troubleshoot this error, follow these steps:
